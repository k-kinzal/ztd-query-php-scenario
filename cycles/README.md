# Investigation history

`python3 scripts/lab.py start <topic>` creates one UTC-named directory under `YYYY/MM/`. Complete the report and record results there. Each `run` creates a separate directory with source/lock references and essential output. Never overwrite a previous observation.

Use `lab.py status` for recent cycles. Start with the relevant scenario or finding to locate older evidence, rather than reading every report. [Workflow](../WORKFLOW.md) · [Record contract](../docs/records.md).
