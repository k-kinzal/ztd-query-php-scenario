# FND-mysqli-multi-query

`multi_query()` on `ZtdMysqli` works for statements without tables (`SELECT 1; SELECT 2`) but fails with `mysqli_sql_exception` 1146 as soon as a statement references a table created in the session, both for `SELECT ...; SELECT ...` and for `INSERT ...; UPDATE ...; SELECT ...`. Native `mysqli` returns the result sets; the ztd-query-mysql spec lists multiple statements as supported.

## Reproduce

From the repository root with PHP 8.1+, `mysqli` and an empty disposable MySQL database:

```bash
composer install
ZTD_MYSQL_HOST=127.0.0.1 ZTD_MYSQL_PORT=3306 ZTD_MYSQL_DB=test ZTD_MYSQL_USER=root ZTD_MYSQL_PASSWORD=root \
  php findings/FND-mysqli-multi-query/repro.php
```

The script runs the same operations on a native `mysqli` connection (physical table, dropped afterwards) and on a `ZtdMysqli` (session-only table) and prints one JSON line per comparison; exit 1 means at least one divergence. Retained outputs: PHP 8.5.8 and 8.1.34 on MySQL 8.0.46 in `cycles/2026/09/CYC-20260926T200050738102Z-mysqli-native-parity/repro/multi-query-php8*-output.txt`; scenario runs in `cycles/2026/09/CYC-20260926T200050738102Z-mysqli-native-parity/runs/`.
