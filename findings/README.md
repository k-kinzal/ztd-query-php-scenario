# Problems and upstream reports

One `FND-<topic>/` directory per observable problem. Keep `finding.json`, a short explanation, standalone `repro.php`, open/closed issue search notes, and links to retained runs and the upstream issue. A blocked submission also needs `issue-body.md` and a blocker.

Report confirmed new problems upstream as part of the same investigation. Reuse an existing report for duplicates. Preserve first-failure evidence when a later run verifies a fix. See [WORKFLOW.md](../WORKFLOW.md#4-report-upstream).
